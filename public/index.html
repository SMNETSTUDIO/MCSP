免费、无需绑卡、无需自备服务器,对 Minecraft 优化。无需在此填写任何参数:
1. 保存配置后点「▶ 启动穿透」,首次会生成绑定链接,打开并登录 playit.gg 完成绑定
2. 在 playit.gg 控制台添加 Minecraft Java 隧道,本地地址填 127.0.0.1:实例端口
3. 绑定信息按实例独立保存,之后启动免绑定
⚠️ ngrok 免费账户使用 TCP 隧道需先在 ngrok 后台绑定一张银行卡(仅验证身份,不会扣费)。 每次启动分配随机地址,例如 0.tcp.jp.ngrok.io:14582。
自建 frps 只需填地址 / 端口 / token;使用 frps-panel 等多用户鉴权插件的服务商,还需填用户名(user)与用户密码(metadatas.token)。

范围 512 ~ 65536 MB;运行中修改需重启实例后生效。
崩溃自动重启:进程非正常退出(退出码非 0)时 5 秒后自动拉起;控制台里手动 stop 或点「停止 / 强杀」不会触发。10 分钟内连续异常退出超过 3 次就停手并在控制台告警, 手动启动后计数清零。
面板重启后自动恢复:只恢复面板停止时正在运行的实例(多个实例每 5 秒拉起一个,避免同时启动抢磁盘); 你主动停掉的实例不会因为面板重启又自己跑起来。

系统设置
「开放注册」是总开关:关闭后即使 OAuth 配置里开着「自动建号」,新身份也无法注册(已有账号不受影响)。 公告修改后立即对所有用户生效;用户关掉的公告再次编辑后会重新弹出。
备份保留策略在每次备份成功后执行,两个条件取并集(任一超限即删)。最新的一份永远保留, 所以把天数调得很短也不会把刚做完的备份删掉。不影响手动删除,也不会去动历史遗留的备份 —— 它们会在下次备份时一并按策略清理。
